货币战争 agent(Windows 便携版)

使用
1. 解压到一个固定的文件夹(路径里最好不要有中文和空格)。
2. 双击 start.bat。第一次运行会请求管理员权限、从米游社官方接口下载游戏数据(约 1 分钟),
   并自动安装开晶矿用的虚拟手柄驱动(ViGEmBus)。
3. 浏览器会打开 http://127.0.0.1:8770 。在「设置」页添加模型厂商(接口地址 + API key)和模型。
4. 游戏用窗口模式、1920x1080、关闭 HDR,进入货币战争界面后在「对局」页开始。
   运行期间不要锁屏,显示器不要休眠。

卸载
双击 uninstall.bat:卸载 cwagent 装的虚拟手柄驱动(电脑上原来就有的不动)、删除防火墙规则,
删除知识库、对局记录、配置(含 API key),最后删除整个文件夹。

风险
第三方自动化违反米哈游用户协议,有封号风险,请只在小号上使用。
