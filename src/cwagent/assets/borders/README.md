# 装备格子边框(活动页样式资源,只作参考)

这几种边框是米游社「货币战争」专题页里装备卡片的样式,用来反推**游戏内装备格子**长什么样:

| 文件 | 来源 | 说明 |
|---|---|---|
| `privilege-board.svg` | `card-border-5-b.40ee945e.svg`(21x21 版) | 特权装备的边框:青色渐变(#34EAE5→#322DFD)+ 右下角**白色 V** |
| `plain-board.svg` | `card-border-6-b.470a7e69.svg`(21x21 版) | 另一种边框:金色渐变(#FEE18C→#BB8E55),右下角没有 V |

关键结论(维护者 2026-11-16 发现):**官方给特权装备和普通装备的是同一张图标**,区别只在外面套的边框。
所以 `vision/equipment.py` 的 `has_v()` 按 `privilege-board.svg` 里那个白色 V 的矢量路径做掩码来判特权,
而不是数"多出来的亮色像素"(那样会把边框本身的描边算进去,把普通装备误判成特权)。

44x44 视口下的 V 路径(与上面 21x21 版等比,`equipment.py` 里的 `V_PATH` 用的就是它):

```
M30.9053 30.2451 L35.0544 39.1594 L39.3274 30.2451 H41.833 L36.356 41.7632 H33.7529 Z
```
